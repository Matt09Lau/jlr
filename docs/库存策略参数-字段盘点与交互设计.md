# 库存策略参数：字段盘点与交互设计

本表描述当前本地实现，列顺序与页面一致。依据层次和未知事项见《库存策略参数-覆盖清单》，不能将演示补充视为当前 UAT 实读结果。

通用：列表只读；详情全部只读；新增/修改仅开放下列标注的维护字段。配件名称、仓库名称联动带出；修改人、更新时间自动记录。结果页只允许人工调整三项。
