## 建储水位线计算结果

最新版按PO 57项、STO 50项分别展示。字段表、查询、来源颜色、超限判断及人工覆盖规则以《建储结果-最新版设计说明》及本次Word需求方案为准，替代旧38列合并设计。


## 最新确认：四项人工调整

PO、STO均支持调整后目标库存、调整后再订购点、调整后最高风控线、调整后最低风控线，弹窗带出当前有效值，列表和导出同步展示；STO再订购点未维护时为空。风控突破按列表字段是/否筛选，各取值来源支持独立筛选；查询紧凑排列。STO同版本按建储日期升序。备货规则位于基础数据菜单，去除ABC/XYZ，支持独立批量修改备注原因。本节覆盖历史说明中的不一致表述。


## 最新调整：审批路径与风控突破方向

- 再订购点突破风控线：显示“突破最高风控线”“突破最低风控线”“否”，等于边界为否；按这三种值筛选，详情和导出一致。
- 增储天数新增申请人，新增必填，修改保留原申请人；列表、查询、详情和导出均展示或支持该字段。演示数据包含计划员和计划经理申请。当前本地通过申请人选项对应身份，正式接入后应由登录身份及组织角色赋值，不能由前端选择替代权限控制。
- 计划员发起：确认 → 待计划经理确认 → 待库存控制高级经理确认 → 审批通过。计划经理发起：确认 → 待库存控制高级经理确认 → 审批通过。批量确认按每条申请人身份分流；驳回、撤回及原配置生效规则保持。
- 菜单“配件风控线规则”统一改为“配件多分类风控线配置”。


## 本次页面调整（覆盖此前冲突说明）

1. 目标满足率服务水平 = 标准正态分布反函数 Φ⁻¹(目标满足率 ÷ 100)，保留6位小数，自动计算只读。95%对应1.644854；目标满足率须在0%与100%之间。
2. 增储天数行操作仅修改及详情；确认、驳回、撤回、计划经理确认、库存控制高级经理确认位于顶部操作区，对勾选记录生效，不显示批量字样。列表新增审批流程提示，计划经理发起仅需库存控制高级经理审批。
3. 两个菜单分别命名为配置多分类风控线、配件风控线，原路由继续兼容。
4. 建储调整弹窗只展示调整后目标库存、调整后再订购点、调整后最高风控线、调整后最低风控线和原因，五项均必填，四项默认当前有效值，不再支持通过留空撤销。
5. STO结果增加再订购点、再订购点突破风控线、风控后再订购点，删除近8周周均销量展示；当前52列。再订购点方向筛选与PO一致。当前为演示快照；STO再订购点生产计算公式仍需确认，旧本地数据补充演示值而不覆盖用户已调整值。


## 审批身份与备货规则最终补充

双角色取最高身份（计划经理）。确认提交时记录申请人、发起角色及审批路径快照，后续角色变更不改变在途审批路径。审批通过后禁止撤销、撤回、驳回；变更通过新的修改申请完成，审批期间原配置继续有效。驳回或撤回的申请可重新确认；顶部按钮按勾选状态启用。演示申请人增加“陈经理（计划员、计划经理）”用于验证。正式登录与审批人组织关系仍需后端接入。

备货规则查询、列表及详情分别展示仓库编码、仓库名称；移除仓库类型展示及筛选。仓库主数据页面的仓库类型不受影响。


## 增储天数展示补充

移除生效状态列、详情字段和查询条件；保留只读的当前生效天数。修改申请尚未审批通过时，按原已批准配置及当前日期显示天数，无可用已批准配置时显示0；该字段用于了解当前配置，不代替建储批次按建储使用日期的取值判断。审批状态继续展示。
