## 已确认规则落实

1. 目标满足率：类型、仓库、目标满足率必填；配件类型必填配件且ABC禁用清空；ABC类型反之。
2. 计划周期：类型与计划周期必填；配件/ABC两类按截图联动，没有增加仓库维度。
3. 备货规则：不使用收货仓与发货仓对应关系；每条仅配件、一个仓库和是否允许备货；批量展开为最小配置单元。
4. 增储天数：新增保存为待审批，确认后待计划经理确认，再待库存高级经理确认，最终审批通过；各阶段均可批量；审批中可驳回、撤回。已通过配置修改后重新审批，旧配置持续按其有效期生效。
5. 结果页：取消旧库存警戒线/代收/累计提前期等字段；建储类型与发货仓、风控后/兜底后/调整后再订购点、月度预测等按新方案展示。水位线、风控、兜底、人工调整、周月预测、其余参数依次展示。
