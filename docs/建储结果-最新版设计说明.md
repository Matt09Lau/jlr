# 建储水位线结果 最新版页面设计

依据《项目需求-迭代 4：库存策略 (5)》5.1.3.3、5.2.3.3的内嵌纵向字段表。用户已确认按STO正文修正冲突字段。

## 页面布局与交互

- 同一入口分PO 建储和STO 建储两个视图，默认PO；切换清空筛选与弹窗并回到第1页。
- 版本号YYYYWW，如202643。PO建储日期为下月1日；STO本周建储对应下周一，下周建储对应下下周一。
- 查询：版本号、配件号、建储仓库编码、风控超限、使用全局参数、全局参数指标；展开后提供配件名称、ABC、计划员、建储日期起止、不建储原因、全局指标值范围。
- 突破风控线按对应列表字段筛选是/否；各来源字段在列头和展开查询中独立筛选配置表/全局参数。
- 初始/风控值与原上下限比较，兜底值与兜底后上下限比较，最终值与调整后上下限比较。越界红底红字；边界相等不算越界。
- 来源为全局参数的指标实际值为橙底橙字，来源标签同色；配置表来源为蓝色标签。
- 人工调整：PO可独立覆盖目标、再订购点、最低/最高线，STO同样支持四项覆盖。原因必填，留空撤销该项覆盖，原始/阶段快照不改写。
- 导出按当前类型生成CSV；查询导出受筛选约束，全量导出为当前类型全部记录，表头顺序和列表一致。

## 纵向字段修订

PO原表57项完整保留，第二组重复的最高风控参数修正为最低风控参数。STO原表52项删除4个再订购点相关字段、按正文修正周指标/LT/周期，再补充风控所需近8周周均销量，补充人工调整后再订购点后得到50项；不使用采购兜底。

## 校验与对接边界

PO须满足最高线≥最终目标>最终再订购点≥最低线；STO须满足最高线≥最终目标≥最低线。不建储记录禁止人工调整。当前数量精度最多2位小数；正式最终取整策略仍需定版。

当前页面使用独立的最新版演示快照，不调用生产指标表或计算任务，不把演示数值作为生产计算引擎的验收结果。真实审批、锁定、跨批次历史查询、Excel异步导出及参数代码映射需后续对接。旧版演示数据未删除。


## 最新确认：四项人工调整

PO、STO均支持调整后目标库存、调整后再订购点、调整后最高风控线、调整后最低风控线，弹窗带出当前有效值，列表和导出同步展示；STO再订购点未维护时为空。目标库存与再订购点突破均按列表字段“突破最高风控线/突破最低风控线/否”筛选，各取值来源支持独立筛选；查询紧凑排列。STO同版本按建储日期升序。备货规则位于基础数据菜单，去除ABC/XYZ，支持独立批量修改备注原因。本节覆盖历史说明中的不一致表述。
