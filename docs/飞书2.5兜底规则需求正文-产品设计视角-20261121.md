## 兜底规则

面向首次接触本模块的读者，描述兜底规则的页面功能与配置方式。

### 背景

系统按需求预测、提前期与风控参数计算配件库存目标。当配件样本不足、属于长尾类别（C/D）或缺少数据时，自动计算结果会偏低，造成补货不足。兜底规则为符合条件的配件提供一个最低保障值 V，作为库存目标的下限保护；当计算结果低于 V 时，以 V 作为保障水平。规则由业务人员在页面上自助维护，不固化为系统内置逻辑。

### 目标

- 业务自助：规则组与分档的新增、编辑、复制、删除均在页面完成。

- 判定确定：多条规则并存时，命中结果唯一、可预期。

- 结果可追溯：命中后写回兜底值与兜底原因，供结果页展示。

- 聚焦配置：页面层级浅、信息密度合理，突出规则本身。

- 口径统一：条件字段来自配件主数据、仓库主数据、指标宽表三类来源。

### 整体架构

兜底规则采用两层判定 + 一个应用判定结构：

```
配件指标数据
  │
  ▼
【第一层】规则组筛选：按优先级升序 → 检查启用状态 → 适用范围全部满足才进入
  │
  ▼
【第二层】组内分档匹配：按序号升序 → 按 AND / OR 判定条件 → 首个命中给出 V 与原因
  │
  ▼
【应用判定】风控后目标库存 S1 < V 时应用兜底，写回 V 与原因；否则沿用风控后结果
```

页面采用左侧规则组列表 + 右侧当前组详情的两栏布局：左侧按优先级列出规则组并提供新增入口，右侧展示当前组的适用范围与分档列表。

### 核心模块（页面功能实现）

#### 可配置参数及用途

条件字段共 36 个，按用途分为以下几类，配置时从下拉中按来源选择：

| 类别归属 | ABC 分类、XYZ 分类、体积分类、金额分类、配件分类、一级分类、二级分类 | 界定配件类别，使不同类别适用不同保障策略；ABC 分类用于规则组之间互斥 |

| 规格与采购属性 | 销售价、最小包装量、起订量、毛重、净重、采购类别、计划员 | 按价格区间、规格或采购属性分档；销售价用于价格档位配置 |

| 特殊件标志 | 无法行驶、是否断供件、是否断点件、是否危险品、是否效期件 | 识别安全件与特殊件，优先给予保障 |

| 仓库 | 仓库编码 | 按仓库限定规则适用范围 |

| 需求指标 | 近 12 周周均销量、近 8 周周均销量、近 8 周需求标准差、近 3 个月月均销量、近 3 月全仓月均销量、近 6 个月需求标准差、近 6 月全仓需求标准差、近 3 个月需求量、近 12 个月需求量、近 12 月全仓需求量、无需求天数、近一年销售频次、兜底 C 类周均销量 | 按需求水平、波动程度或销售频次分档 |

| 预测指标 | 下周人工预测、下月仓库人工预测、下月全仓人工预测 | 按未来放量预期分档 |

字段按来源归入配件主数据（19 个）、仓库主数据（1 个）、指标宽表（16 个）三组展示。其中"近一年销售频次"取指标宽表权威口径：按配件号统计最近 12 个月销售数量大于 0 且非空的数据行数，用于高频件的卖一补一分档。

配置值的录入方式：

- 枚举配置：枚举类参数（如 ABC 分类、体积分类、采购类别、各类标志位）以枚举项下拉方式选择，可多选；

- 文本配置：文本类参数（如仓库编码、配件分类、计划员）以包含 / 不包含方式匹配，录入一个或多个文本值；

- 数值配置：数值类参数录入具体数值或区间上下限；

- 空值配置：选择为空 / 不为空时无需录入值。

#### 规则组

规则组是独立的配置单元，包含组名、执行优先级、启用状态、描述、组编码，以及一组适用范围条件。组编码由系统自动生成，不在界面展示。适用范围至少一条条件且必须包含 ABC 分类条件，使各组适用对象互斥。规则组按执行优先级升序判定，数值越小越先。

#### 分档

每个规则组持有独立的分档列表，组间互不影响。每个分档包含：序号（组内唯一，升序判定）、条件逻辑（AND / OR）、条件集合、兜底值 V（非负整数）、兜底原因（必填）、启用状态。

分档不设档位名称，以兜底原因作为分档的标识文本，命中后写入结果，使命中依据一眼可辨且可追溯。分档允许不带条件：在适用范围已限定的组内，无条件分档默认命中，适合固定 V 值场景。

#### 条件配置

条件由字段、操作符与值三部分构成。选定字段后，操作符按字段类型自动过滤：

- 枚举字段：操作符为等于 / 不等于 / 属于 / 不属于，值从枚举项下拉中选择；

- 文本字段：操作符为包含 / 不包含，值手工录入；

- 数值字段：操作符为等于 / 不等于 / 大于 / 大于等于 / 小于 / 小于等于 / 区间，值录入数值或上下限。

条件按分档的 AND / OR 逻辑组合；适用范围的条件固定为 AND（全部满足）。

#### 规则引擎

规则引擎依据配置执行匹配：对单条件求值、对分档按 AND / OR 求值、对适用范围求值、按优先级与序号取首个命中。所有接口为纯计算，不依赖界面与存储，相同输入始终得到相同结果。

#### 配置界面

- 左侧规则组列表显示组名、启用状态、优先级、分档条数，点击切换当前组；顶部提供"+ 规则组"入口。

- 右侧详情区显示组信息、适用范围条件与分档列表，提供编辑组与适用范围、复制组、删除组操作；删除组需二次确认。

- 分档卡片显示序号、兜底原因、启用状态、条件与兜底值，提供上移、下移、复制、编辑、删除操作。

- 规则组与分档的新增、编辑均通过弹窗完成；弹窗内可增删条件。

- 必填项以星号标识；校验失败即时提示具体原因并阻止保存；取消或关闭弹窗不写入改动；保存成功给出反馈。

#### 配置存储

规则配置以规则组集合的形式保存在浏览器本地。无配置时页面展示一组示例数据供参考与试用，示例数据非系统内置规则，业务可自由增删改。

### 页面交互设计

本节从用户操作视角说明页面交互行为、状态变化与系统反馈，作为「配置界面」中界面元素的补充。页面以"先选组、再配分档"为主线，所有编辑集中在弹窗内完成，列表与卡片始终只读，避免误操作。

#### 布局与导航

- 页面采用左右两栏：左栏为规则组列表，右栏为当前组的详情。左侧选中项以高亮标识，切换组时右栏内容随之更新；切换组会关闭当前打开的分档编辑弹窗，避免跨组残留。
- 左栏按执行优先级升序排列规则组，每组展示组名、启用状态、优先级数值与分档条数，点击任一组即可在右栏查看与编辑。
- 左栏顶部固定"+ 规则组"入口；右栏顶部展示当前组名、优先级、启用状态与描述，并提供编辑组与适用范围、复制组、删除组三个操作。首次进入或无可编辑组时，右栏显示空状态引导。

#### 列表与卡片交互

- 适用范围以条件条展示，每条按"字段 · 操作符 · 值"的顺序呈现，条件之间固定为 AND（全部满足），条数在标题处实时显示。
- 本组分档以卡片列表展示，仅显示启用状态的分档，按序号升序排列；卡片以兜底原因作为标题（未填写时显示占位提示），避免因缺少档位名称而出现空白标识。
- 每张分档卡片展示序号、兜底原因、启用状态、条件表达式与兜底值；无条件时显示"无条件（本组默认命中）"，条件之间以 AND / OR 文字连接。
- 卡片底部提供上移、下移、复制、编辑、删除五个操作：上移 / 下移通过交换相邻序号调整判定顺序，到达边界时不响应；复制生成独立新档位并追加到末尾；删除即时生效。
- 停用的规则组或分档以灰色或默认标签弱化显示，仍保留在列表中可随时重新编辑启用。

#### 弹窗编辑交互

- 规则组与分档的新增、编辑均在弹窗中完成。新增规则组时优先级自动取当前最大值加十，适用范围预置一条 ABC 分类条件，便于快速形成互斥分组；新增分档时序号自动取当前最大值加十，默认启用、兜底值为五、无兜底原因。
- 编辑规则组会带出原有配置并复制一份数据，编辑过程中取消或关闭不写入；新建不生成组编码，编辑沿用原编码，编码不在表单展示。
- 弹窗内可增删条件。新增条件默认取字段列表首项及其首个操作符、空值；切换字段时，系统自动同步字段标签与值类型，并把操作符重置为该字段支持的首个、清空已录入的值，避免出现字段与操作符不匹配。
- 值的录入控件随字段类型切换：枚举字段为可多选的下拉，数值字段为数字输入框，区间为上下限两个输入框，文本字段为文本输入框；选择为空 / 不为空时隐藏值输入区。

#### 校验与反馈

- 必填项以星号标识。保存时执行校验：规则组需有组名、优先级及至少一条含 ABC 分类的适用范围条件；分档需有唯一序号、非负兜底值与必填兜底原因。
- 校验不通过时，以错误提示集中列出原因并阻止关闭弹窗与写入，用户修正后可再次保存；校验通过后保存成功给出轻提示。
- 枚举字段在编辑态以数组承载多选值、在保存态拼接为逗号分隔文本，输入框与存储之间自动转换，用户无感知。
- 所有改动即时写入本地配置：新增、编辑、复制、删除、上移、下移保存后立即生效并刷新列表，无需额外提交步骤。

#### 危险操作与边界交互

- 删除规则组需二次确认，提示将同时删除其下所有分档，确认后左栏选中项自动切换到第一条可用组；删除分档、复制、上移下移为轻量操作，直接生效。
- 无规则组、组内无分档、无选中组三种情况分别显示对应空状态引导，页面不出现空白或报错。
- 分档上移 / 下移在首末位置不可继续；序号重复时保存被拦截并提示，保证判定顺序唯一确定。

### 关键流程

#### 规则配置流程

- 新增规则组：填写组名、优先级、状态、描述，配置至少一条含 ABC 分类的适用范围条件，校验通过后保存。

- 在选中组内新增分档：填写序号、兜底值、状态、必填的兜底原因，选择 AND / OR，按需添加条件，校验通过后保存。

- 同类规则通过复制规则组（含分档副本）或复制分档快速创建，再修改差异项。

- 通过改优先级或上移 / 下移调整判定顺序；不再适用的组或分档可删除，删除组需二次确认。

#### 匹配与兜底应用流程

- 取得待判定配件的指标数据，装配为字段名到实际值的映射。

- 按优先级升序遍历规则组：跳过停用组；适用范围全部满足才进入，否则继续下一组。

- 进入某组后按序号升序遍历启用分档：按 AND / OR 判定条件，首个命中分档给出候选兜底值 V 与兜底原因。

- 全部未命中则无兜底结果；命中后以风控后目标库存 S1 与 V 比较：S1 < V 时应用兜底并写回 V 与原因，S1 ≥ V 时不应用、沿用风控后结果。

### 操作符集合

| EQ | =（等于） | 枚举 / 文本 / 数值 / 标志位 |

| NE | ≠（不等于） | 枚举 / 文本 / 数值 / 标志位 |

| GT | >（大于） | 数值 / 文本 |

| GE | ≥（大于等于） | 数值 / 文本 |

| LT | <（小于） | 数值 / 文本 |

| LE | ≤（小于等于） | 数值 / 文本 |

| BETWEEN | 区间 | 数值 |

| IN | 包含 / 属于 | 文本 / 枚举 |

| NOT_IN | 不包含 / 不属于 | 文本 / 枚举 |

| IS_NULL | 为空 | 支持空值判定的字段 |

| IS_NOT_NULL | 不为空 | 支持空值判定的字段 |

操作符按字段值类型过滤；枚举字段以枚举项下拉选择值，文本字段以包含 / 不包含方式录入，区间录入上下限两个值，为空 / 不为空无需录入值。

### 异常处理

| 规则组或分档停用 | 不参与匹配 |

| 规则组无适用范围条件或缺 ABC 分类条件 | 不参与匹配；保存时被校验拦截 |

| 分档序号重复、兜底值为负、兜底原因为空或仅空白 | 校验拦截保存 |

| 条件字段取值为空 | 仅"为空"操作符命中，其他操作符不命中 |

| 数值字段值无法解析为数值 | 该条件不命中 |

| 区间上下限缺失或非法 | 该条件不命中 |

| 分档无条件 | 在适用范围已限定的组内默认命中 |

| 全部规则未命中 | 无兜底结果，沿用风控后结果 |

| 命中但 S1 ≥ V | 不应用兜底，沿用风控后结果 |

| 命中且 S1 < V | 应用兜底，写回兜底值与兜底原因 |

| 存储不可用或内容损坏 | 页面使用示例数据展示，不影响打开 |

### 约束与假设

- 数据来源：条件字段仅来自配件主数据、仓库主数据（仓库编码）、指标宽表三类；全局参数类字段（提前期、目标满足率、风控系数、备货标识等）不作为条件。

- 互斥与顺序：规则组适用范围必须含 ABC 分类条件以保证互斥；按优先级与序号升序取首个命中，这是确定性匹配的保证。

- 兜底值：为非负整数，表示最低保障件数；兜底原因必填，作为分档标识与命中依据。

- 价格档位：价格分档不是独立机制，通过销售价字段与普通条件表达，业务可自由调整档位与阈值。

- 模块边界：本模块负责维护规则、执行匹配、产出候选兜底值与原因；不负责建储结果的最终计算。

- 使用假设：规则合理性由业务负责；首次启用需按实际口径配置正式规则；配置量在可手工维护范围内。

### 验收要点

- 可完成规则组与分档的新增、编辑、复制、删除，可增删条件、切换 AND / OR、调整优先级与序号。

- 字段下拉按配件主数据 / 仓库主数据 / 指标宽表三类来源分组；枚举项为下拉多选，文本为包含 / 不包含。

- 校验生效：兜底原因必填、序号唯一、兜底值非负、适用范围含 ABC 分类；校验失败有提示并阻止保存。

- 各规则组按适用范围互斥、不跨类抢占；按优先级与序号取首个命中；停用的组与分档不参与匹配。

- 命中且 S1 < V 时写回兜底值与原因；S1 ≥ V 或未命中时不写兜底、沿用风控后结果。

- 删除规则组有二次确认；取消或关闭弹窗不写入改动。
