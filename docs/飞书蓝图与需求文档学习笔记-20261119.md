## 一、项目全景（蓝图）

- 背景：JLR 全球平台 JLRS 计划 2026 年底下线，需建设本地 CSPP 系统替代，并与全球 IPOS、CJLR SAP 集成（分 Phase 1/2）。
- 功能需求 86 项，关键模块：基础数据管理（配件/仓库/经销商/供应商主数据、BOM、替代关系、保有量、库存/在途）、需求预测（模型管理、预测计算、准确率 MAPE/WAPE/Bias、自动分类）、库存策略优化（服务水平、LT、安全库存、Min/Max、多级仓网、审批版本）、备货与去库存、库存调拨/网络优化、停产备货（Last Time Buy）、呆滞库存、执行监控、报表、权限日志、IPOS/SAP 集成。
- 非功能需求：可用性 99.5%、故障转移容灾、JLR 登陆区安全合规、RBAC + 审计日志、传输与静态加密、模块化可升级、REST/GraphQL 标准接口、操作留痕可溯源、成本优化。
- 仓网：1 个中心仓 + 5 个区域仓；中心仓承担采购备货与向区域仓供货，区域仓承担区域需求保障。
- 库存审批决策变更：2026-09-20 决定**审批增储参数，不审批建储结果**；2026-09-21 决定**备货规则不需要审批**。
- 决策变更：2026-10-29 决定**常规 PO/STO 建储的补货量 Q 不采用 EOQ**，改用 (S,s) 模型、Q = 7 天量，通过本周与未来 1 周计划指导物流降本；doc3 另注明「长期方案：决策 C0、Ch 计算逻辑后使用 EOQ」。此决策**不适用于停产末采（All time buy）**——末采场景仍按 MPQ/MOQ/EOQ 取整，属不同业务对象。

## 二、库存策略与指标宽表（doc3，核心）

### 2.1 水位线与补货模型

- 周期盘点 (T,s,S) 与连续盘点 (s,S)：`IP = OH + OO − BO`；当 `IP ≤ s` 时 `Q = S − IP`，否则 0。
- 目标库存 `S = d̄·(T+LT) + SS`；安全库存 `SS = z·σ_d·√(T+LT)`；再订购点 `s = d̄·LT + z·σ_d·√LT`。
- PO 建储按配件 + 中心仓计算，STO 建储按配件 + 区域仓计算；风控线对目标库存与再订购点分别做上限/下限约束。

### 2.2 指标宽表

- 定位：统一汇总「配件维度」与「配件+仓库维度」的公用指标，避免同一指标在不同模块重复计算、口径不一。
- 计算频率：每周（在预测之后）；四舍五入最多保留 2 位小数。
- 范围：配件号取配件主数据.最新配件号；配件+仓库维度按配件号 + 发货仓库（= 配件主数据.收货仓库）查库间 LT 配置表取收货仓库。
- 指标分两类：配件维度 16 项（过去 N 月销量、当月预测、未来 N 月预测、未来 1~6 月近 3 月月均销量、近 6 月需求标准差、近一年销售频次）；配件+仓库维度 27 项（过去 N 周销量、当周预测、未来 N 周预测、未来 1~12 周近 12 周周均销量、近 8 周需求标准差）。

### 2.3 兜底规则（权威定义，doc3）

| 场景 | 条件 | 兜底逻辑 |
|---|---|---|
| C 类兜底 | ABC=C **且 月均销量<8** | 按销售价 8 档：空/≤0.01→5；>0.01≤2→50；>2≤20→10；>20≤60→8；>60≤200→6；>200≤500→5；>500≤2000→4；>2000→3 |
| D 类兜底 | ABC=D | 按销售价 8 档（与上同） |
| S/E 类兜底 | ABC∈S1/S2/S3/E **且 近一年频次≥1** | 频次≥3→3；频次 1~2→2（卖一补一） |
| S0 类兜底 | ABC=S0 **且 配件主数据.无法行驶=是** | 兜底值=1 |

- **近一年频次口径（权威）**：近 12 个月（T-12~T-1，按订单日期）、销售数量>0 且非空的数据行数；按配件号统计（配件维度）。蓝图早期版本为「按最新替代件号 + 仓库编码(首发仓) + 订单月分组」，doc3 已改为按配件号匹配指标宽表.近一年频次。
- **兜底应用（权威，2026/11/13 由 min 改为 max）**：
  - 仅当「能匹配到兜底值 且 风控后目标库存 < 兜底值」才应用：
    - 兜底后目标库存 = `max(风控后目标库存, 兜底值)`
    - 兜底后再订购点 = `向上取整(兜底值 × 0.75)`
    - 兜底后最低风控线 = `向上取整(兜底值 × 0.5)`
    - 兜底后最高风控线 = `max(风控后目标库存, 兜底值)`
  - 否则：兜底值置空，兜底后四项 = 风控后四项。
- 结果页：PO 57 字段、STO 52 字段；「是否应用兜底值」仅 PO，条件为「风控后目标库存 < 兜底值」。
- 人工调整优先级：`调整后 = ifnull(人工录入, 兜底后, 风控后)`。

### 2.4 蓝图早期兜底定义的差异（已被 doc3 覆盖）

| 项 | 蓝图（早期） | doc3（当前权威） |
|---|---|---|
| C 类条件 | ABC=C 且 **周均销量<2** | ABC=C 且 **月均销量<8** |
| D 类逻辑 | 按**近一年频次**分档（≥3→3，1~2→2） | 按**销售价 8 档** |
| N 类兜底 | 有（ABC=N，销售价 8 档） | **无 N 类** |
| S/E 兜底 | 无独立条目 | 有（频次卖一补一） |

## 三、权威字段表（已实际读取嵌入表格）

### 3.1 配件主数据（工作表 `ods_material_info_di`，69 个字段）

表名 `JLR-数据模型字典`，来源 IPOS / 人工导入 / 自动计算。关键字段：

- 标识：`material_code` 配件号、`new_material_code` **最新配件号**（预测/指标宽表均以此为准）、`material_name`
- 分类：`abc_classification` ABC 分类（按订单行占比 A<45%、B 45-75%、C 75-90%、D 90-97%、E 剩余；S0/S1/S2/S3 为一年内 0/1/2/3 次）、`parts_classify` 配件分类、`tier1_category`/`tier2_category`、`part_type` 配件类型、`purchase_type` 采购类别（Y 外购 / IH 自制 / D 直供经销商）
- 数值：`sales_price` 销售价（ZSTK 订单类型最新单价，考虑币种）、`min_package_qty` 最小包装量、`min_order_qty` 起订量、`gross_weight`/`net_weight`、`volume`、`length`/`width`/`height`
- 标志：`potential_unit_down` **无法行驶**（枚举是/否）、`is_cut_off_part` 断供件、`is_break_point_part` 断点件、`is_dangerous_goods` 危险品、`is_expiry_part` 效期件、`is_direct_supply` 直供件、`is_all_time_buy` 一次买断、`is_new` 新件、`is_activities` 活动件、`localisation_status` 国产化标识
- 其他：`planner` 计划员、`delivery_planner` 交付计划员、`vehicle_code` 车型代码、`model_year` 停产车型年款、`eop_date` 停产时间、`belonging_area_code` 所属收货仓、`manufacturer_part_no` 工程件号、`common part` 通用件号

### 3.2 指标宽表（`FxmYsA73.../oz8Oxl`，43 项指标）

- 配件维度：过去 N 月销量（最多 6 月）、当月预测、未来 N 月预测（最多 6 月）、未来 1~6 月近 3 月月均销量、未来 1~6 月近 6 月需求波动标准差、`近一年销售频次`。
- 配件+仓库维度：过去 N 周销量（最多 12 周）、当周预测、未来 N 周预测（最多 12 周）、未来 1~12 周近 12 周周均销量、未来 1~12 周近 8 周需求波动标准差。
- 关键口径：月均销量为滚动窗口（过去 + 当月预测 + 未来预测）；近一年频次按配件号统计近 12 月销售数量>0 且非空的订单行数。

### 3.3 与当前配置页字段注册表的对照（重要）

- 当前 `fallback-rule.js` 用**驼峰演示字段名**（`abcClassification`/`salesPrice`/`demand_month_avg_3m` 等），权威表用 **snake_case + 中文指标名**（`abc_classification`/`sales_price`/`未来1月近3个月月均销量`/`近一年销售频次`）。演示映射与实际接口字段需在后端落地时对齐。
- 更新（2026-11-20）：频次字段已对齐权威「近一年销售频次」——配置页字段注册表改用 `sales_frequency_1y`（展示名"近一年销售频次"），S/E 示例组条件同步替换，删除自定义 `positive_order_line_cnt_12m` / `_all`。
- 当前「配件主数据 19 字段」基本覆盖权威表中的分类/数值/标志字段，但**权威表还有 50 个字段未纳入**（新件、国产化、工程件号、停产日期等）；如业务需要更多条件字段，应按权威表扩充。
- 当前「指标宽表 22 字段」中部分为演示构造（`demand_month_avg_3m_all`、`days_since_last_demand`、`fallback_c_week_avg`、`forecast_*`），**权威指标宽表无这些字段**；原 `positive_order_line_cnt_12m_all` 已移除并改用权威「近一年销售频次」（`sales_frequency_1y`），该项待映射已关闭。
- 上一轮「字段来源收窄」已删除 9 个全局参数字段（目标满足率/服务水平Z/增储天数/LT/计划周期/风控系数/库间LT/备货标识），它们确实属于**参数配置表**（doc3「库存策略-参数配置」），不属于配件主数据/指标宽表，方向正确。

## 四、预测模块要点（doc2）

- 四大场景：参考零件预测（新件借用相似车型/零件历史）、常规件预测、长周期预测与 EOP 一次买断、预测模拟；均含业务背景/需求/流程/计算逻辑/页面交互。
- 准确率指标 MAPE / WAPE / Bias；历史回测支持配置训练/验证/结果时间区间。
- 前期迭代调整：配件主数据、经销商主数据（需求、第一优先发货仓）、保有量数据、订单监控预警。
- 预测结果同步 SAP：由系统接口传输。
- 与兜底的关系：预测结果是指标宽表的输入（当月预测、未来 N 月预测），进而影响建储目标库存 S 与再订购点 s。

## 五、计划管理要点（doc4）

- 采购计划：以「调整后目标库存 − 全网预期库存」为缺口，按 MOQ / 联合 MOQ / 成套采购 / MPQ 逐层凑整；单个配件上限取最高风控线；紧急计划每天凌晨判断预期库存是否低于**调整后最低风控线**。
- `预期库存 = open PO + 可用库存 + 调拨在途 − BO`（按收货仓库汇总）。
- 采购计划输出字段含：目标库存（建储推荐.调整后）、最低风控线（建储推荐.调整后）、最高风控线、近 3 月月均销量、当前可用天数。
- STO 调拨计划、Bridge buy / All time buy、参考零件采购计划、给供应商的滚动计划、给仓库的预计调拨计划、自动下单（文件下载/覆盖/上传机制，上传待定）。
- 与兜底的关系：兜底值经「调整后目标库存 / 调整后最低风控线」间接驱动采购计划的触发与数量上限，**计划模块不直接读取兜底值**。

## 七、待确认与建议

1. **字段命名对齐**：当前驼峰演示字段与权威 snake_case/中文指标名的映射表需业务+后端确认，尤其「月均销量<8」取哪个指标（未来 1 月近 3 月月均销量？）。
2. **近一年频次口径**：蓝图「替代件号+首仓+订单月」vs doc3「按配件号指标宽表」，当前实现用 `positive_order_line_cnt_12m_all`（演示名），需映射到指标宽表「近一年销售频次」。
3. **D 类无销量门槛**：权威 doc3 中 D 类只有 ABC=D 条件，当前实现一致；蓝图早期有频次门槛，不要回填。
4. **N 类兜底**：doc3 无 N 类，如业务仍需 N 类应单独提需求。
5. **0.01~2 元 → V=50 尖峰值**：三份文档一致，属原始设计（非笔误），保留。
6. **兜底公式落地**：建议将「仅 S1<V 应用 + 四项公式 + 不建储前置」下沉到后端计算引擎，并在结果页展示「是否应用兜底值」「兜底原因」。
7. **字段注册表扩充**：如需更多条件字段，按权威配件主数据 69 字段、指标宽表 43 指标补齐，避免演示字段与真实字段脱节。
8. **D/S0 兜底是「并且」还是分档**：doc3 表格文字用「并且」把两个前置条件连写，但实际语义是「前置条件（AND）+ 分档条件」，与当前实现的组级 scope + 档位 conditions 两层结构一致；无需改动，仅记录措辞歧义。
9. **指标精度**：指标宽表四舍五入最多 2 位；销售价在配件主数据为 `decimal(15,4)`。兜底价格档边界对比时要注意 2 位与 4 位精度差异（如 0.01 边界）。
10. **参数取数层级**：doc3 中 PO/STO 目标满足率均为三级取值（配件号+建储仓 → ABC+仓库 → 全局默认），当前前端只演示全局层；这属于参数配置来源，不进入兜底档位条件（上一轮已剔除该 9 个参数字段，方向正确）。
